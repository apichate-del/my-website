🚀 GitHub Pages Hosting

คู่มือสร้างเว็บไซต์ฟรีด้วย GitHub Pages

ขั้นตอนทั้งหมด

1️⃣ สร้าง Repository

สร้าง Repository ใหม่บน GitHub ตั้งชื่อโปรเจกต์และเลือก Public

2️⃣ เพิ่มไฟล์เว็บ

สร้างหรืออัปโหลดไฟล์ index.html, style.css และรูปภาพ

3️⃣ เปิด GitHub Pages

ไปที่ Settings → Pages เลือก Deploy from a branch

4️⃣ เลือก Branch

Branch = main Folder = /(root) แล้วกด Save

5️⃣ รอ Deploy

GitHub จะสร้างเว็บไซต์ให้อัตโนมัติ ภายในไม่กี่นาที

6️⃣ เว็บไซต์ออนไลน์

เข้าชมเว็บไซต์ผ่าน URL ของ GitHub Pages ได้ทันที
